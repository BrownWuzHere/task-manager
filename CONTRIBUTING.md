Hey everyone, thanks for checking out my task manager project.

I built this to practice modular JavaScript and use design patterns like Observer and Strategy.

The code works but it can definitely be cleaner, so feel free to jump in and edit it.

Here is how you can set it up locally:

1. Fork this repo to your own GitHub account.

2. Clone it to your computer using git clone.

3. Open it with a local server like VS Code Live Server because ES6 modules will block a direct double-click on index.html.

4. Push your changes to a new branch and open a Pull Request.
